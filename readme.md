# Java Database CRUD

Aplicación de consola desarrollada en Java para la gestión de datos mediante MySQL, JDBC y exportación a CSV.

## 🚀 Funcionalidades

- Gestión de datos mediante una base de datos MySQL
- Operaciones CRUD
- Consulta y gestión de registros
- Exportación de datos a formato CSV
- Conexión con MySQL mediante JDBC

## 🛠️ Tecnologías utilizadas

- Java
- MySQL
- JDBC
- Eclipse IDE
- Git
- GitHub
- CSV

## 📂 Estructura del proyecto

```text
src/
├── Alumno.java
├── GestorBaseDeDatos.java
├── GestorFicheros.java
└── Start.java

conector/
└── mysql-connector-java-5.1.15-bin.jar

exportar.csv
```

## 🗄️ Base de datos

El proyecto utiliza MySQL para almacenar y gestionar los datos.

La conexión con la base de datos se realiza mediante JDBC utilizando el conector de MySQL incluido en el proyecto.

## 📄 Exportación CSV

El proyecto incluye funcionalidades para exportar los datos gestionados a un archivo `CSV`, permitiendo trabajar con la información fuera de la aplicación.

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio.
2. Importar el proyecto en Eclipse.
3. Configurar la base de datos MySQL.
4. Comprobar la configuración de conexión.
5. Ejecutar `Start.java`.
